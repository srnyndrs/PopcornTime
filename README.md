# Popcorn Time
<h3 style="color:#FFFF78"><b>Currently In Progress</b></h3>

Android application to search TV Shows, Movies and related People.

The application is using the [TMDB API](https://developer.themoviedb.org/reference/intro/getting-started) and [JustWatch](https://apis.justwatch.com/docs/api/) to provide data.

## Technologies
- Jetpack Compose
- Retrofit
- Dagger Hilt
- Coil
- Paging
- DataStore
- Clean Architecture
